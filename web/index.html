Kiln

A tiny typed language, compiled to WebAssembly as you type.

hello.kiln
idle 

      

      

        
Programs

        
fn main() runs once. fn frame(t: float) runs every animation frame, with t in seconds. The screen is WIDTH × HEIGHT (320 × 240) and colors are 0xRRGGBB.

        
Values

        
let x = 3;            // immutable, type inferred
var y: float = 1.5;   // mutable
const N = 64;         // compile-time constant
var grid: [int; N * N];   // arrays live at top level
let pal = [0xff0000, 0x00ff00];
let s = "text";       // strings: len(s), s[i] gives a byte

        
Types: int (32-bit), float (64-bit), bool, str, and your own structs. Nothing converts silently: write x as float. Integer literals do adapt to floats, so x * 2 works.

        
Structs

        
struct Vec2 { x: float, y: float }
struct Ball { pos: Vec2, vel: Vec2, color: int }

var balls: [Ball; 64];          // arrays of structs
const UP = Vec2(0.0, 1.0);      // built like a call

fn length(v: Vec2) -> float { return sqrt(v.x * v.x + v.y * v.y); }

var b = Ball(Vec2(10, 20), UP * 3.0, 0xff8800);
b.pos += b.vel * dt;            // component-wise math
balls[0] = b;                   // structs are values: this copies
balls[0].vel.y -= 1.0;

        
Methods

        
impl Vec2 {
  fn zero() -> Vec2 { return Vec2(0.0, 0.0); }      // Vec2.zero()
  fn length(self) -> float {                       // v.length()
    return sqrt(self.x * self.x + self.y * self.y);
  }
  fn grow(var self, k: float) { self *= k; }       // v.grow(2.0) changes v
}

        
self is a copy of the value the method is called on. A var self method changes that value, so it can be called on variables, array elements and fields, but not on temporaries. A method without self is called on the type.

        
Structs whose fields are all floats (or all ints) support + - * / % with each other and with a single number. Any struct supports == and !=. print(v) shows Vec2(1.0, 2.0).

        
Operator methods

        
impl Complex {
  fn *(self, o: Complex) -> Complex { ... }   // z * w
  fn *(self, k: float) -> Complex { ... }     // z * 2.0
  fn *(k: float, z: Complex) -> Complex { ... } // 2.0 * z
  fn -(self) -> Complex { ... }               // -z
  fn <(self, o: Complex) -> bool { ... }      // also gives > <= >=
}
z = z * z + c;   // + falls back to component-wise

        
Define + - * / % == != < <= > >= in an impl, and unary - with just self. Overloads are picked by operand type, and the struct can be on either side. != comes from ==, and > <= >= from <. Anything you don't define keeps the built-in behavior, and compound assignment like z *= w uses your operator. Small operators and methods are inlined, so they cost about the same as writing the math out.

        
SIMD vectors

        
let v = f32x4(1.0, 2.0, 3.0, 4.0);  // four 32-bit floats in one register
let k = i32x4(7);                     // 7 in all four lanes
let w = v * 2.0 + v;                  // lane by lane; a scalar fills all lanes
v.x                                   // read a lane (x y z w) as a float
let m = v > 2.5;                      // boolx4: one bool per lane
if any(m) { }                         // any(m), all(m)
let r = select(m, v, 0.0);            // pick per lane
n += m as i32x4;                      // true -> 1, false -> 0
let d = f64x2(0.1, 0.2);              // two 64-bit floats; d < 0.15 gives a boolx2

        
f32x4 supports + - * / % and comparisons. i32x4 supports + - *, comparisons, & | ^ ~ and shifts by an int, but not /, because WebAssembly SIMD can't divide integers. f64x2 has the same operations as f32x4 in double precision, with lanes x y. Masks (boolx4, boolx2) combine with & | ^ !. sqrt floor ceil trunc round abs min max clamp work lane by lane, and as converts between types with the same number of lanes. to_bits(v) reads an f32x4's bit patterns as an i32x4 and from_bits(i) turns them back, at no cost (the julia example uses them for a four-wide log2). Vectors can be locals, parameters, return values, struct fields, globals and array elements. Use them to shade four pixels per loop iteration, or two in double precision (the mandelbrot example).

        
Sound

        
beep(440.0, 0.2);                     // frequency in Hz, seconds
sound(WAVE_SQUARE, 880.0, 1760.0, 0.1, 0.4);  // wave, from Hz, to Hz, seconds, volume
sound(WAVE_NOISE, 3000.0, 60.0, 0.6, 0.9);    // noise: an explosion
sound_at(t + 0.5, WAVE_TRIANGLE, note(60), note(60), 0.3, 0.5);

        
Waves: WAVE_SQUARE WAVE_TRIANGLE WAVE_SAW WAVE_SINE WAVE_NOISE. The pitch slides from the first frequency to the second. note(n) turns a MIDI note number into Hz (60 is middle C). sound_at schedules on the same clock as t and now(), which keeps music in time. Browsers only allow sound after you click or press a key on the page.

        
Control flow

        
if a < b { } else if c { } else { }
while cond { break; continue; }
for i in 0..10 { }    // 0 to 9
for i in 1..=10 { }   // 1 to 10
let m = a > b ? a : b;

        
Operators

        
+ - * / % · == != < <= > >= · && || ! · & | ^ ~ << >> >>> · compound += etc. Bitwise operators bind tighter than comparisons.
