Kiln

A tiny typed language, compiled to WebAssembly as you type.

hello.kiln
idle 

      

      

        
Programs

        
fn main() runs once. fn frame(t: float) runs every animation frame, with t in seconds. The screen is WIDTH × HEIGHT (320 × 240) and colors are 0xRRGGBB.

        
Values

        
let x = 3;            // immutable, type inferred
var y: float = 1.5;   // mutable
const N = 64;         // compile-time constant
var grid: [int; N * N];   // arrays live at top level
let pal = [0xff0000, 0x00ff00];
let s = "text";       // strings: len(s), s[i] gives a byte

        
Types: int (32-bit), float (64-bit), bool, str, and your own structs. Nothing converts silently: write x as float. Integer literals do adapt to floats, so x * 2 works.

        
Structs

        
struct Vec2 { x: float, y: float }
struct Ball { pos: Vec2, vel: Vec2, color: int }

var balls: [Ball; 64];          // arrays of structs
const UP = Vec2(0.0, 1.0);      // built like a call

fn length(v: Vec2) -> float { return sqrt(v.x * v.x + v.y * v.y); }

var b = Ball(Vec2(10, 20), UP * 3.0, 0xff8800);
b.pos += b.vel * dt;            // component-wise math
balls[0] = b;                   // structs are values: this copies
balls[0].vel.y -= 1.0;

        
Structs whose fields are all floats (or all ints) support + - * / % with each other and with a single number. Any struct supports == and !=. print(v) shows Vec2(1.0, 2.0).

        
Control flow

        
if a < b { } else if c { } else { }
while cond { break; continue; }
for i in 0..10 { }    // 0 to 9
for i in 1..=10 { }   // 1 to 10
let m = a > b ? a : b;

        
Operators

        
+ - * / % · == != < <= > >= · && || ! · & | ^ ~ << >> >>> · compound += etc. Bitwise operators bind tighter than comparisons.

        
Built in

        

          
Math
sqrt floor ceil trunc round abs min max clamp sin cos tan asin acos atan atan2 exp log pow fract mix smoothstep sign

          
Drawing
pixel(x, y, c) · get_pixel(x, y) · clear(c) · rect(x, y, w, h, c) · circle(x, y, r, c) · line(x0, y0, x1, y1, c) · the screen array

          
Color
rgb(r, g, b) with ints 0..255 · rgbf(r, g, b) with floats 0..1 · hsv(h, s, v) · blend(a, b, t)

          
Text
text(x, y, s, c) · text_big(x, y, s, size, c) · number(x, y, n, c) · text_width(s) · print(a, b, ...)

          
Input
mouse_x() mouse_y() mouse_down() · key_down(code) with KEY_LEFT KEY_RIGHT KEY_UP KEY_DOWN KEY_SPACE KEY_ENTER, or a letter's code like 65 for A

          
Random
rand() in 0..1 · hash(n) · hash2(x, y) · hashf(n) · noise(x, y) · fbm(x, y, octaves)

          
Other
select(cond, a, b) · len(array or string) · PI · TAU

        

        
Keys

        
Ctrl+Enter runs from the start · Ctrl+/ comments lines · click the screen to give it the keyboard.
